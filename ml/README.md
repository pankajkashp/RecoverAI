# ML Pipeline

This directory contains the ML pipeline structure for training, evaluation, and model artifacts.

## Subdirectories

| Directory    | Purpose                                |
|-------------|----------------------------------------|
| `data/`     | Raw and processed training datasets    |
| `features/` | Feature engineering scripts            |
| `training/` | Model training pipelines               |
| `evaluation/`| Model evaluation and metrics          |
| `models/`   | Trained model artifacts                |

## Status

Phase 1 — directory structure only. No ML training, predictions, or models implemented.
